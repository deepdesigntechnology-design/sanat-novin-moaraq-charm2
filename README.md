# صنعت نوین معرق چرم

**وب‌سایت آموزشی و علمی** برای معرفی جامع صنعت نوین معرق چرم.

---

## درباره پروژه

این مخزن شامل یک وب‌سایت استاتیک (HTML + CSS) است که صنعت نوین معرق چرم را به‌صورت علمی و آموزشی معرفی می‌کند.

- **پدیدآورنده شیوه:** استاد افشین خلیلی  
- **کد استاندارد شغل در سند مرجع:** ۷۵۳۶-۷۷-۰۰۲-۱ (معرق‌کار چرم)  
- **کد داخلی پروژه:** ۱-۰۲-۰۰-۷۷-۶۵۳۷  
- **گروه:** خلاقیت‌های تجسمی ایده — عرصه سیمرغ — اصفهان  

## صفحات وب‌سایت

| صفحه | توضیح |
|------|--------|
| `index.html` | صفحه اصلی و معرفی کلی |
| `about.html` | تعریف صنعت، تمایز با سوخت چرم، اهداف |
| `structure.html` | ساختار ۸ فصلی + ۱۰ بخشی هر فصل |
| `techniques.html` | تکنیک‌های پایه، قوام‌آوری و تکمیلی |
| `glossary.html` | واژه‌نامه تخصصی فیکس‌شده |
| `standard.html` | استاندارد رسمی شغل و تطبیق توانایی‌ها |

## مشاهده آنلاین

نشانی انتشار GitHub Pages:

`https://deepdesigntechnology-design.github.io/sanat-novin-moaraq-charm2/`

صفحهٔ انتشار در مخزن فعال پیکربندی شده است؛ وضعیت هر انتشار را می‌توان در زبانهٔ Actions بررسی کرد.  

## ویژگی‌ها

- طراحی RTL و فونت وزیرمتن  
- کاملاً استاتیک و بدون وابستگی  
- محتوای مبتنی بر متون فیکس‌شده پروژه آموزشی  
- مناسب برای هنرجویان، مربیان و معرفی عمومی صنعت  

## مجوز

محتوای آموزشی متعلق به پروژه صنعت نوین معرق چرم است. استفاده آموزشی با ذکر منبع آزاد است.
